L'image est l'oeuvre ; le NFT est le token auquel elle est assiciee

Creer une image(avec un 42) avec un numero(identifiant)
Stocker cette image sur IFPS et aussi 
Fiche de descprition de l'image = les metadonnées(titre,auteur,lien vers l'image)
Le certificat numeroté de l'image = le NFT , identifié par son tokenId dans un contrat
Le registre public des certificats et propriétaires = la blockchain
Le programme qui applique les règles du registre = le smart contrat

Objectif:
Creer une image - preparer sa fiche descriptive - programmer le registre
inscrire le NFT sur le blockchain de test

BNB Smart Chain Testnet
└── Contrat NFT
    └── NFT n° 1
        ├── Propriétaire : adresse de ton wallet
        └── Référence vers les métadonnées sur IPFS
            └── Référence vers ton image sur IPFS

Le but du projet est de créer ton propre NFT et de comprendre toute la chaîne :
1. Tu crées une image contenant 42 : c’est ton œuvre.
2. Tu stockes cette image sur un système distribué, comme IPFS.
3. Tu prépares sa fiche descriptive, appelée métadonnées : titre comprenant 42, ton login comme artiste et lien vers l’image.
4. Tu développes et déploies un contrat sur une blockchain de test.
5. Tu crées ton NFT avec ce contrat : il possède un identifiant, un propriétaire et une référence vers les métadonnées.
Le résultat attendu est donc : un NFT associé à ton image, dont tu peux vérifier le propriétaire et afficher l’œuvre.
